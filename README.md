## What I build

- **Recruiting Systems** — 후보자·고객사·공고·전형·일정·소싱 데이터를 하나의 운영 흐름으로 연결
- **HR & Labor Systems** — 근태, 노무 Case, 계산, 문서, 공식절차와 권한·감사 구조 설계
- **Workflow Automation** — 반복 입력·문서 생성·검수·리포트·AI 보조 업무를 실제 운영 기준으로 자동화
- **Operational Prototypes** — 업무에서 발견한 문제를 빠르게 제품 구조로 검증하고, 필요한 기능은 후속 시스템에 통합

## Selected Projects

### SearchDB
**Recruitment Operations Database & Candidate Discovery**

후보자·고객사·채용공고·전형 진행·일정·이력서 데이터를 관리하는 내부 채용 운영 시스템입니다.  
공개 웹과 기술 활동을 활용한 인재 탐색 기능을 기존 후보자 DB 흐름에 연결하고, 탐색 결과를 바로 저장하지 않고 검토 후 전환하도록 설계했습니다.

`Next.js` · `TypeScript` · `PostgreSQL` · `Prisma` · `Candidate Discovery`

### 인사야 · Insaya
**HR / Labor Problem-Solving Platform**

근로자와 사업주가 노무 문제를 구조화하고, 계산·문서·공식 근거·절차·전문가 연결까지 이어갈 수 있도록 설계한 Case 중심 플랫폼입니다.  
법률 적용과 계산은 자유로운 AI 생성보다 deterministic Rule과 Legal Governance를 우선하며, 공식 출처 변경도 사람의 검토 없이 운영 Rule로 자동 반영하지 않습니다.

`Node.js` · `PostgreSQL` · `Case Engine` · `Legal Governance` · `AI`

### The Lobby
**Candidate Portal & Recruiting Platform**

후보자의 채용공고 탐색·프로필·지원 경험과 리크루터의 Talent Pool·전형 파이프라인·커뮤니케이션을 연결하는 채용 플랫폼 프로젝트입니다.  
내부 운영 DB와 후보자-facing 경험을 분리해 각각의 인증·데이터·배포 경계를 독립적으로 검증하고 있습니다.

`Next.js` · `TypeScript` · `Firebase` · `Recruiting Workflow` · `AI Resume Intake`

### HR Attendance System
**Attendance, Leave & Audit Workflow**

출퇴근·자리비움·복귀·근무시간, 휴가·연장근로와 관리자 운영을 다루는 HR 시스템입니다.  
단순 근태 기록을 넘어 RLS, 권한 분리, 다중 근무 세션, immutable audit log와 관리자 보정 흐름을 함께 설계했습니다.

`Next.js` · `TypeScript` · `Supabase` · `PostgreSQL RLS` · `Audit Log`

## How I work

```text
현장 문제 확인
→ 업무 흐름 분해
→ 데이터 구조 / 권한 / 예외 정의
→ 작은 기능으로 검증
→ 테스트와 운영 기준 추가
→ 중복 프로젝트·기능 통합
→ 실제 사용 기준으로 반복 개선
```

기능 수를 늘리는 것보다 **업무 흐름이 끊기지 않는지, 데이터가 안전한지, 운영자가 실제로 사용할 수 있는지**를 우선합니다.
