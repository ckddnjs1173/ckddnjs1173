## About

채용·인사 운영 실무에서 반복되는 문제를 **프로세스 → 데이터 → 도구**로 바꾸는 작업을 하고 있습니다.

- **Recruitment Operations** — 후보자, 공고, 전형, 일정, 현장 운영 데이터 구조화
- **HR / Labor Operations** — 근태, 연차, 계약, 노무·컴플라이언스 업무 지원
- **Workflow Automation** — 반복 입력, 문서 처리, 검수, 리포트 업무 자동화
- **AI-assisted Tools** — LLM과 규칙 기반 로직을 업무 흐름에 안전하게 결합하는 실험

> 화려한 데모보다 실제 업무에서 다시 쓸 수 있는 구조, 검증 가능한 로직, 운영 가능한 흐름을 우선합니다.
