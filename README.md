## 👋 About me

채용과 HR 운영 실무를 하면서 생기는 반복 업무를 그냥 처리하는 데서 끝내지 않고,
**프로세스 → 데이터 → 도구**로 바꾸는 방식에 관심이 있습니다.

- 채용 운영 데이터와 업무 흐름 설계
- HR / 노동업무 지원 도구 개발
- 반복 문서·검수·리포트 자동화
- AI와 규칙 기반 로직을 결합한 업무 도구 실험

현재 프로젝트들은 완성품으로 고정하기보다, 실제 사용하면서 계속 기능을 합치고 개선하는 방식으로 운영하고 있습니다.
